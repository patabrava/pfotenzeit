# Audio assets

No audio files ship in the MVP. All cues are synthesised at runtime with WebAudio in
`src/audio/AudioManager.ts` (soft confirm, chime, single soft tone, filtered-noise breath).

If clips are added later, list each here with source, licence, duration and byte size
(budget ≤ 2 MB total, see 06_ART_DIRECTION). Dog sounds stay sparse and never replace body language text.
