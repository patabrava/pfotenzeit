# Spielvision

## Versprechen

„Ich lerne meinen Welpen kennen und werde mit ihm ein besseres Team.“ Der Hund ist eine individuelle Figur, keine Sammlung von Gehorsamspunkten. Die Schule gibt Abwechslung und Orientierung; das eigene Tier sorgt für Bindung.

Die Person ist Schüler:in und Mitgestalter:in der Schule, keine gewinnorientierte Betreiberfigur. Mira führt durch die ersten Besuche. Kleine gemeinsame Erfolge verbessern das Gelände für alle. Es gibt keinen wirtschaftlichen Druck und keine Kundenwarteschlangen.

## Warum diese Kombination?

Ein reines Tamagotchi kann zu wiederholtem Abarbeiten von Bedürfnissen werden. Eine reine Schulverwaltung schafft weniger persönliche Bindung. Pfotenzeit verknüpft Pflege, konkrete Trainingsentscheidungen und räumlichen Fortschritt. Gastwelpen zeigen, dass eine passende Lösung vom einzelnen Hund abhängt.

## Spielerhandlungen

Beobachten, Bedürfnis versorgen, Übung vorbereiten, Signal geben, Belohnung auswählen, Schwierigkeit reduzieren, Pause machen, Fortschritt ansehen, Schule verbessern. Alle Handlungen funktionieren mit einer Hand und einzelnen Berührungen. Kein virtueller Joystick, keine freie Laufsteuerung, kein präzises Zielen.

## Unterhaltung

Nala entdeckt eine neue Schnüffelecke, Bruno lässt sich von einem Blatt ablenken, Mira freut sich über eine passend gewählte Pause. Kleine Geschichten und glaubwürdige Reaktionen ersetzen hektische Aufgaben. Varianten ändern relevante Umstände, nicht bloß die Farbe einer Aufgabe.

## Grenzen des Prototyps

Eine Schule, ein eigener Welpe, ein Gastwelpe, eine Trainerin, eine Gastbesitzerfigur; drei Lektionen, zwei kleine Ausbauten, ein sichtbarer Wachstumsschritt. Größere Casts und erwachsener Hund ausschließlich Roadmap. Keine offene Stadt, Zucht, Wettbewerbe oder reale medizinische Simulation.

## Erfolgskriterien

Neue Nutzer verstehen ohne Erklärung, wie sie das Profil öffnen, ein Bedürfnis versorgen und eine Lektion beginnen. Eine vollständige Sitzung dauert im Median 3–5 Minuten. Nach einer Lektion können sie den Lernpunkt in eigenen Worten erklären. Die Entscheidung „Pause“ fühlt sich hilfreich an und bringt Fortschritt.
